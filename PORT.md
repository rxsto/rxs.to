## Remaining differences and limits

The visible portfolio matches the source. The Lucide icon is rendered as SVG instead of an Iconify CSS mask, which leaves a few minor rasterization differences. Tailwind line-height tokens are fixed to the source build's serialized values to preserve its layout.

Robots and sitemap files preserve indexing and URLs, without Nuxt module comments, generation timestamps, or its sitemap stylesheet. Framework internals, asset URLs, and default error pages belong to vinext. No custom Nuxt error page existed in the source.

Vite reports upstream source-map and dynamic-import warnings. The build completes. vinext reports the home page's static classification as unknown; it is served by the Worker. No prerendering or page cache is configured.

The new Worker's API key must be set by the deploying lead. No deployment, push, domain move, DNS change, or write to the live KV namespace was performed. Cloudflare authentication and production behavior remain for the lead's deployment check.
