# Stack icons

Paths from [Simple Icons 11.15.0](https://github.com/simple-icons/simple-icons/tree/11.15.0/icons), distributed under [CC0-1.0](LICENSE.md). The SVGs are unmodified upstream assets; the site uses them as monochrome CSS masks. Product names and marks belong to their respective owners.

Files: typescript, nuxtdotjs, kotlin, terraform, amazonaws, bun, hono, nextdotjs, vuedotjs, rust, kubernetes.

Only icons used by the project pages are retained. Each uses an equal 1em box and an optical scale: TypeScript/Kotlin .78, Next.js .85, Terraform/Vue .9, Bun/Hono .95, Nuxt/Rust/Kubernetes 1, AWS 1.1. Icons use the muted colour; visible names use regular foreground text. Stack labels remain in the existing project data, including the Digital Office 24 stack derived from the CV.
